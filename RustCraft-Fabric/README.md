# RustCraft (Fabric, Minecraft 1.21.4)

Мод нужен и на сервере, и у игроков (в одиночной игре просто положите jar в mods).
Требуется Fabric Loader и Fabric API для 1.21.4.

## Сборка
1. Поставьте JDK 21.
2. Если нет Gradle wrapper (gradlew): установите Gradle 8.12+ и выполните `gradle wrapper`,
   либо скачайте пустой шаблон на https://fabricmc.net/develop (1.21.4) и скопируйте в него папку `src`.
3. `./gradlew build` (Windows: `gradlew.bat build`).
4. Готовый мод: `build/libs/rustcraft-1.0.0.jar` (без `-sources`). Положите в папку `mods`.

## Игра
- Новичок получает План строительства и Молоток (отключается в `config/rustcraft.json`).
- План: ПКМ — построить, Shift+ПКМ — следующий элемент. Контур показывается частицами.
- Молоток: ПКМ по элементу — улучшить (дерево → камень → металл), Shift+ПКМ — снести (первые 10 минут).
- C4: ставится ПКМ у стены, взрывается через 5 секунд. Крафт: порох/редстоун/TNT.
- Команды (оп): `/rustcraft kit`, `/rustcraft c4`, `/rustcraft airdrop`.
- Постройки хранятся в `rustcraft.json` в папке мира, настройки — в `config/rustcraft.json`.

## Шкаф (Tool Cupboard) — приват
- В плане есть элемент «Шкаф»: ставится на верх фундамента или перекрытия (ПКМ планом, целясь в пол).
- ПКМ по шкафу — авторизоваться / снять авторизацию. Shift+ПКМ пустой рукой — очистить список.
- В зоне шкафа (по умолчанию 32 блока) строить, улучшать, сносить и ставить обычные блоки могут только авторизованные.
- Шкаф можно уничтожить C4 (2 взрыва) — тогда защита пропадает. Радиус и прочность — в `config/rustcraft.json`.

## Содержание и распад построек
- Постройки **без шкафа** в зоне разрушаются: раз в час (`upkeepIntervalMinutes`) теряют целостность — дерево 20%, камень 10%, металл 5%.
- **Шкаф** списывает материалы на содержание: ПКМ по шкафу с досками (дерево), булыжником (камень) или железными слитками (металл) вносит всю стопку в запас (только авторизованным).
  Пока материалов хватает, постройки не разрушаются и чинятся на 25% за интервал. Расход — `upkeepPerPiece` на элемент за интервал.
- Молоток в руке показывает целостность элемента, статус шкафа и на сколько часов хватит запаса.

## Выживание и худ
- Новый худ в правом нижнем углу: **еда** (ванильная), **вода**, **температура тела**. Нужен мод и на клиенте.
- Вода убывает со временем (быстрее при беге и жаре). Пить: Shift+ПКМ пустой рукой по воде, либо бутылки с водой/зелья, молоко, мёд, арбуз.
  При воде 0 — иссушение (эффект Иссушения), ниже 15% — слабость.
- Температура зависит от биома, времени суток, дождя, высоты, пещер, воды, огня рядом (костёр, печь, лава) и одежды (кожаная броня греет сильнее всего).
  Ниже 5 °C — замерзание (ванильный урон от холода, кожаная броня защищает), выше 32 °C — вода тратится быстрее.
- После смерти вода 60%, температура 22 °C. Выключить: `survivalEnabled: false` в `config/rustcraft.json`.

## Сборка jar без установки Java (GitHub Actions)
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки (вместе с `.github`).
2. Откройте вкладку Actions, дождитесь зелёной галочки (или нажмите Run workflow).
3. Откройте завершённый запуск и скачайте артефакт `rustcraft-jar` — внутри готовый `rustcraft-1.0.0.jar`.
4. Положите jar в папку `mods` рядом с Fabric API для 1.21.4.
